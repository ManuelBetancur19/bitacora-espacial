# Bitácora Espacial

Portal de noticias de exploración espacial hecho con React y Vite, con un sistema de estilos propio en CSS (tokens, capas, grid con subgrid y container queries).

## Cómo correrlo

1. Instala las dependencias:

   npm install

2. Copia `.env.example` a `.env`:

   cp .env.example .env

3. Inicia el servidor de desarrollo:

   npm run dev

Abre http://localhost:5173

## API

Datos de [Spaceflight News API](https://api.spaceflightnewsapi.net/v4/docs/). Es gratuita y no requiere clave.
